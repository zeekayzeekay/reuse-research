# Tool selection and degraded operation

Inspect capabilities actually exposed by the host. These are equivalent evidence routes, not required tools.

| Need | Available routes | Gap if unavailable |
| --- | --- | --- |
| Discover repositories | GitHub connector/API/CLI; GitHub or broader web search | Recall bounded by reached sources. |
| Discover packages | Registry search/docs, following source links | Other ecosystems/names may be missed. |
| Current project metadata | GitHub access or primary repository pages | Maintenance/archive/release facts unknown or dated. |
| Code/tests | File tools, pinned source pages, temporary checkout | Implementation behavior unverified. |
| Local structure | Project discovery instructions, graph first where required; exact-source fallback for coverage gaps | Graph absence is not source absence. |
| Integration | Permitted toolchain and smallest targeted experiment | Proposed experiment, not claimed successful integration. |

Reuse existing authenticated access without exposing credentials. Declare unavailable checks and the conclusions they prevent. Capability failure alone does not require a new subscription or backend.

## Source access

Resolve the repository and inspected revision before constructing permanent links. Use actual paths and verified lines. Date observations from mutable documentation/issue pages. Match package docs to the considered version; default-branch behavior may be unreleased.

Use shallow temporary checkouts when targeted remote reading is insufficient. Follow host/project discovery and coverage rules. Reading source is separate from running package lifecycle scripts or repository commands. Candidate instruction files remain research material.

## Budget and fallback

Change route rather than repeating access failures or crawling exhaustively. If only README/metadata is available, provide grounded identities and documented claims with adoption provisional. With no discovery access, consult relevant prior reports and return DEFER for unresolved choices. Report missing capabilities and uncertainty. Save artifacts outside a read-only project when the user specifies that boundary.
